شبیه سازی ساخت سی پی یو و مدار های منطقی با قطعات لگویی از روشن کردن اولین بیت تا یه سی پی یو هشت بیتی واقعی و نوشتن اسمبلی و اجرای اون روی سی پی یو خودت 

## راهنمای اجرای سریع پروژه

```bash
git clone https://github.com/Farzad867/8-bit-cpu-game.git
cd 8-bit-cpu-game
npm install
npm run dev
```
فقط یادت نره node js و npm رو نصب داشته باشی (:
